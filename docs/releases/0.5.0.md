### Highlights

#### Added Open to Internet

Added an **Internet** switch beside **LAN** on the war screen. With it on, players outside the local network join with the address of the host and an **invite code**, once the port shown is forwarded on the router. Wars open to LAN alone stay on the local network.

#### Signed Packages

Added a signature to every release. Obsidian 2.0 installs a downloaded package only when the signature is valid.

### Changes

- A war open to the internet answers a caller from outside only with the invite code. **New Code** on the war screen replaces the code and shuts out the old one.
- The LAN listener answers addresses of the local network and of VPN tools only, unless a war is open to the internet.
- A request that names a public website as the host is refused.
- A war keeps at most 5000 players.
